# X-Tip Playground

Premium Discord + WhatsApp + Telegram combined UI playground for Android – built with Expo.

## Features
- Dark premium UI
- Discord-style servers & channels
- WhatsApp-style chat list + status stories
- Telegram-inspired clean messaging
- Bottom tab navigation (Chats · Servers · Status · Profile)

## Run it

```bash
git clone https://github.com/blitzlabx/x-tip-playground.git
cd x-tip-playground
npm install
npx expo start
```

Then:
- Press `w` for web (works in mobile browser)
- Scan the QR with **Expo Go** on your phone
- Or press `a` for Android emulator
